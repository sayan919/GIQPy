--------------------------------------------------------------------------------
0. IMPORTANT CONSTRAINTS (what hyphens can and cannot touch)
--------------------------------------------------------------------------------
- CLI flags        : hyphens are ideal. argparse maps "--num-monomers" to
                     args.num_monomers automatically (user-facing name is
                     hyphenated, code stays valid).
- Filenames        : hyphens fine for scripts that are RUN, and for output files.
                     EXCEPTION: functions.py is IMPORTED, so it cannot take a
                     hyphen (Python can't import a hyphenated module name).
- Code identifiers : variables / function names CANNOT use hyphens ('-' is the
                     minus operator). They stay snake_case (PEP8).
=> Hyphen preference realistically applies to: CLI flags, filenames, and
   human-readable text (comments / titles / log messages).
